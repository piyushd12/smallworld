smallworld

Find the shortest follow chain between two GitHub users.

Running without a GitHub token — limited to 60 requests/hour. See the README to add one.

    How it works

    The search grows two breadth-first searches at once — one outward from the source account, one outward from the target's — and stops as soon as they meet. Each round it expands whichever side currently has fewer people to check, and prioritizes accounts that many others already point to, since those tend to be hubs that connect to more of the graph.

    A chain can be missed even when one exists: GitHub's follower and following lists are paginated and this app only checks a limited number of pages per account, the search stops once it reaches the configured maximum degrees, a single search spends at most 400 GitHub requests, and it stops entirely once the hourly rate limit runs out. When no chain is found, that means none was found within those limits — not that no connection exists.

    Every GitHub answer is cached on the server for days, so accounts that show up in many searches are only fetched once, and repeating a search costs almost nothing.

    Uses the public GitHub API. Nothing you search is stored on the server.
